# 🪙 Gold & Silver Price in Egypt 🇪🇬

A clean and simple **Flutter application** that displays the current prices of **Gold and Silver** in Egypt.

## ✨ Features

- 📈 Displays real-time prices of **Gold** and **Silver**
- 🇪🇬 Prices shown in **Egyptian Pounds (EGP)**
- 📱 Responsive layout for all devices
